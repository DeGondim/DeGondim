## Sobre mim

Sou desenvolvedor de software e aplicações com foco em Python, desenvolvimento web, banco de dados, automação de processos e inteligência de negócios. Tenho experiência na criação de soluções para melhorar rotinas operacionais, integrar sistemas, organizar dados e transformar informações em relatórios e dashboards úteis para tomada de decisão.

Minha atuação combina desenvolvimento backend, interfaces web, consultas SQL, integrações com bancos de dados e automações voltadas para ambientes corporativos. Já trabalhei em projetos envolvendo planejamento, apontamento de mão de obra, conexão com SAP Business One, relatórios com Excel e SQL, além de soluções para monitoramento e visualização de dados em usinas fotovoltaicas.

Estou sempre em busca de novos desafios para aplicar tecnologia de forma prática, escalável e orientada a resultado.
