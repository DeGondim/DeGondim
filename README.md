## Sobre mim

Sou desenvolvedor de software e aplicacoes com foco em Python, desenvolvimento web, banco de dados, automacao de processos e inteligencia de negocios. Tenho experiencia na criacao de solucoes para melhorar rotinas operacionais, integrar sistemas, organizar dados e transformar informacoes em relatorios e dashboards uteis para tomada de decisao.

Minha atuacao combina desenvolvimento backend, interfaces web, consultas SQL, integracoes com bancos de dados e automacoes voltadas para ambientes corporativos. Ja trabalhei em projetos envolvendo planejamento, apontamento de mao de obra, conexao com SAP Business One, relatorios com Excel e SQL, alem de solucoes para monitoramento e visualizacao de dados em usinas fotovoltaicas.

Estou sempre em busca de novos desafios para aplicar tecnologia de forma pratica, escalavel e orientada a resultado.
